Telas de aula

O que é projetado na aula, aqui no seu celular. Abra a tela do módulo que estamos vendo e acompanhe pelos números dos blocos.

Isto não substitui o caderno. As telas são o roteiro da exposição, curtas e diretas. O material de estudo, mais aprofundado e suficiente para as avaliações, é o caderno de módulos.

Como acompanhar

  1. Cada tela tem um número no alto, do tipo 5/12. É por ele que o professor chama: “bloco cinco”.
  2. Role a página de cima para baixo. Não há botão de avançar — é rolagem comum.
  3. Onde houver tabela, deslize a tabela para o lado com o dedo: ela continua além da borda da tela.
  4. A página não gasta dados depois de aberta. Se a internet cair, o que já carregou continua ali.
